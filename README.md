# Estragon

**Declarative UI and reactive data binding for Godot.**

Estragon is an early-stage project inspired by the developer experience of Adobe Flex 3/4. Its declarative UI source format is called **Gogo** (`.gogo`).

The compiler, reactive bindings, and Godot editor integration are being designed and scaffolded. See the repository's pull requests for active implementation work.

> *No more waiting for Godot. Gogo!*
